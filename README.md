# CodeAlpha Java Internship Tasks

This repository contains the Java projects completed as part of my CodeAlpha internship.

## Tasks

### Task 1 - Student Grade Tracker
A console-based Java application that:
- Accepts student names and scores
- Stores student data using ArrayList
- Calculates the average score
- Finds the highest and lowest scores
- Displays a student summary report

### Task 2 - Stock Trading Platform
A console-based Java application that:
- Displays stock market data
- Allows users to buy and sell stocks
- Tracks the user's portfolio
- Calculates portfolio value
- Maintains transaction history
- Simulates stock price updates
- Uses Object-Oriented Programming (OOP)

## Technologies Used

- Java
- ArrayList
- Object-Oriented Programming
- Console-based interface
